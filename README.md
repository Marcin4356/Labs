# Labs

A collection of practical Python exercises and experiments covering programming, data analysis, and machine learning.

## Overview

The repository contains separate laboratory exercises used to develop Python and data-oriented programming skills. The work includes notebooks, scripts, datasets, and reusable helper code.

## Topics

- Python fundamentals
- Data structures and functions
- File handling
- Data analysis with Pandas and NumPy
- Statistical analysis
- Supervised machine learning
- Classification and regression
- Model evaluation
- Basic neural networks

## Technologies

- Python
- Pandas
- NumPy
- scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook
- TensorFlow

```
Labs/
```

Run the notebooks with Jupyter or execute the Python exercises directly.
